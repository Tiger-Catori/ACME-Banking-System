# ACME-Banking-System

Welcome to the **ACME Banking System**! 
A Console-driven banking system for bank tellers.
This project is a robust and secure banking application designed to manage accounts, transactions, and customer data efficiently.

---

## Features

- **Account Management**: Create, update, and manage customer accounts.
- **Transactions**: Deposit, withdraw, and transfer funds securely.
- **User Authentication**: Secure login system for customers and admins.
- **Reporting**: Generate detailed account and transaction reports.
- **Scalable Architecture**: Extendable modules for future enhancements.
